# **App Name**: MusicalBox

## Core Features:

- Virtual Keyboard & Drum Pads: Interactive visual interface that allows users to play instrument sounds via on-screen elements (e.g., piano keys, drum pads) using keyboard or mouse input.
- Diverse Instrument Selection: Ability for users to switch between a curated set of popular virtual instruments (e.g., ukulele, piano, xylophone, drums, guitar, violin, flute, clarinet) available in the application.
- Real-time Audio Playback: Plays high-quality audio samples corresponding to the selected instrument and user interaction in real-time.
- Intuitive Instrument Controls: User-friendly controls for basic adjustments such as volume, and toggling of effects for the selected virtual instrument.
- Responsive User Interface: Ensures the application interface adapts seamlessly to various screen sizes and devices for an optimal online playing experience.
- Customizable Key Colors: Allows users to change the color of the keys for instruments like piano, xylophone, ukulele, etc.

## Style Guidelines:

- Dark Mode: Immersive, studio-like feel with deep violet primary elements (#6A0DAD) and dark purple-grey background (#1A161C).
- Light Mode: Minimalist black and white scheme for a clean and modern look.
- Accent color: A bright, energetic electric blue to highlight interactive controls, call-to-action buttons, and active states, providing excellent contrast (#4F55EE).
- Headlines and body text use 'PT Sans', a humanist sans-serif that balances modern readability with a touch of warmth, suitable for diverse interface elements.
- Minimalist and clear iconography, using musical symbols (e.g., note, metronome, speaker) and simple control glyphs that are easily recognizable.
- Clean, focused, and intuitive layout that prioritizes the virtual instrument on screen, with secondary controls positioned for easy access.
- Subtle visual feedback animations on key presses, pad hits, and control interactions to enhance responsiveness and user engagement.
